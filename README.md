# Pesquisa Pré-Evento

Formulário de pesquisa pré-evento para gestantes. Envia respostas via webhook n8n e gera token de acesso ao curso "O Dia do Parto" (válido até 10/jul/2026).

- Site: https://pesquisa.manualdorecemnascido.com.br
- Webhook: `POST /webhook/baby-talks-pesquisa`
- Workflow n8n: `Pesquisa | Receber`
